Remnant 2 Unlocker - Setup Instructions
========================================


Quick start (recommended)
-------------------------

1. Download the latest version from Nexus Mods:
   https://www.nexusmods.com/remnant2/mods/215
   (also on GitHub: https://github.com/EX0Sk1tz/Remnant-2-item-spawner-UI/releases)
   Unpack the zip and run Remnant2UnlockerApp.exe.

2. On the first start the app asks where to install itself (default:
   %LocalAppData%\Programs\Remnant2Unlocker) and can create a desktop
   shortcut. "Run without installing" keeps it where it is.

3. The setup wizard opens and does the rest:
   - finds your game (Steam, Epic or Game Pass), or lets you choose the folder
   - asks you to close the game if it's running
   - installs everything the mod needs. The one thing you download yourself
     is "Allow Asset Mods" from Nexus Mods (https://www.nexusmods.com/remnant2/mods/2):
     click "Open Nexus page", download the main file, and drop the .zip/.rar/.7z
     onto the wizard (or use "Choose file..."). Optional: Summonable Traits
     (https://www.nexusmods.com/remnant2/mods/122) the same way.
   - "Install / Repair" installs the Remnant2Unlocker mod, the stack size /
     item level support, and switches the mods on in mods.txt
   - checks that your antivirus didn't remove UE4SS again
   - starts the game once and waits until the mod reports in

That's it. You never have to copy folders or edit text files.

- Open the wizard again any time: Settings > General > "Repair / update
  installation".
- After an app update, the mod files in the game are updated automatically
  on the next start (if the game is running, the app asks first; restart the
  game afterwards).
- Everything the app replaces in the game folder is backed up first, into
  Mods\Remnant2Unlocker\Backups. "Undo last change" in the wizard puts the
  latest backup back.
- Steam installs under C:\Program Files (x86) need administrator rights to
  write to. The wizard offers "Restart as administrator" when that happens.


Manual installation (fallback)
==============================

Only needed if the wizard can't be used. The game folder below is:

    Steam/Epic: ...\Steam\steamapps\common\Remnant2\Remnant2\Binaries\Win64
    Game Pass:  ...\XboxGames\Remnant 2\Content\Remnant2\Binaries\WinGDK

"Win64\Mods" below means the folder UE4SS loads mods from. If your UE4SS sits
in a "ue4ss" subfolder (Win64\ue4ss\UE4SS.dll), that is Win64\ue4ss\Mods
instead - on Steam and Epic too. See "Nested ue4ss folder / Game Pass" below.


1. Install UE4SS + AllowModsMod ("Allow Asset Mods")
----------------------------------------------------

Remnant 2 blocks mods by default. The "Allow Asset Mods" package on Nexus
Mods bundles UE4SS (the framework that runs Lua mods), UE4SS's standard mods
(ConsoleCommandsMod, ConsoleEnablerMod, CheatManagerEnablerMod, ...) and
AllowModsMod, the patch that lets the game load them. No other package is
needed.

1. Download the main file from https://www.nexusmods.com/remnant2/mods/2
2. Extract the FULL contents directly into the Win64 folder.
3. If an older UE4SS left an xinput1_3.dll there, delete it.
4. Antivirus / Windows Defender often quarantines UE4SS.dll right after
   extraction, because it hooks into the game. If things disappear, restore
   them from the quarantine and add an exclusion for the Binaries folder.


2. Install the Remnant2Unlocker mod
-----------------------------------

The release zip contains a folder called "Remnant2Unlocker". Copy that
folder into Win64\Mods. The app keeps its files up to date afterwards.

Stack size and item level: the app replaces UE4SS's
Mods\ConsoleCommandsMod\Scripts\summon_unloaded_assets.lua with a version
that understands them. Without it items still spawn, one at a time at level 0.
The wizard / "Install / Repair" installs it; manually you can take it from
the repo folder "Lua Scripts inside game directory\ConsoleCommandsMod\Scripts".


3. (Optional) Summonable Traits
-------------------------------

Only needed to spawn Trait / Core Trait / Archetype Trait items. Download it
from https://www.nexusmods.com/remnant2/mods/122 and extract its mod folder
into Win64\Mods.


4. Enable the mods
------------------

Open Win64\Mods\mods.txt (some UE4SS versions use Mods\enabled.txt) and make
sure these lines exist with " : 1". Add missing ones ABOVE the
"; Built-in keybinds, do not move up!" line:

    AllowModsMod : 1
    ConsoleCommandsMod : 1
    ConsoleEnablerMod : 1
    CheatManagerEnablerMod : 1
    Remnant2Unlocker : 1

(plus the Summonable Traits folder name, if installed).


5. Start the game, then the app
-------------------------------

Start Remnant 2 once, then run Remnant2UnlockerApp.exe and select the Win64
folder when asked (choosing the game's main folder works too).


Nested ue4ss folder / Game Pass
-------------------------------

Newer UE4SS builds (the UE4SS console shows "v3.0.1 Beta"; Allow Asset Mods
may ship one) load through a dwmapi.dll proxy and keep everything in a
"ue4ss" subfolder. This happens on Steam and Epic (Win64\ue4ss\Mods) as well
as on the Xbox/Microsoft Store (WinGDK) build. A leftover Win64\Mods folder
from an older UE4SS is then ignored by UE4SS - put the mods in ue4ss\Mods.
For Game Pass, UE4SS v3.0.1 is known to work:

    https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/v3.0.1

The Game Pass layout looks like this (Steam/Epic: Win64 instead of WinGDK):

    WinGDK
    |- Remnant2-WinGDK-Shipping.exe
    |- dwmapi.dll
    `- ue4ss
       |- UE4SS.dll
       `- mods
          |- Remnant2Unlocker, AllowModsMod, ConsoleCommandsMod, ...
          `- mods.txt / enabled.txt

The app and the wizard detect both layouts; always select the Win64 / WinGDK
folder itself. Game Pass setups are more fragile than Steam/Epic, and AllowModsMod
has been reported to crash the Store version with mismatched UE4SS builds.


Troubleshooting
===============

Run Diagnostics (the icon in the app) first - it names the missing piece and
"Copy Report" gives you something to paste when asking for help. The setup
wizard (Settings > "Repair / update installation") fixes most problems.

Spawn does nothing:
  Run the wizard's "Install / Repair" and check Diagnostics.

No UE4SS console window appears when the game starts:
  UE4SS never loaded - almost always antivirus quarantining UE4SS.dll (or
  dwmapi.dll on Game Pass). Restore it and add an exclusion.

Stack size / item level is ignored:
  The patched summon command is missing (Diagnostics: "Stack size & item
  level support"). Run "Install / Repair".

Some items crash or fail to spawn:
  Use "Force" or "Copy" instead - some assets are unstable through direct
  spawning.

Traits won't spawn or Add is blocked:
  Summonable Traits is missing or not enabled - install it in the wizard.


Notice
======

Teleport will kill you if the vertical distance downwards would be lethal
through falling. Upwards has no restriction - best used against a surface.
Pressing Shift (Sprint) while trying to Teleport will not work. Any
environment blocking your character's path to the target location will
result in a shorter teleport. Think of it as a very fast fly mod - line of
sight must be clear.
